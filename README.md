\# TaskMate Android



TaskMate merupakan aplikasi manajemen tugas berbasis Android yang membantu pengguna dalam membuat, mengatur, dan memantau aktivitas harian secara lebih terstruktur.



Aplikasi ini dikembangkan menggunakan Kotlin dengan Jetpack Compose untuk menghasilkan tampilan modern dan responsif.



\## 📱 Fitur Aplikasi



\### Dashboard Task

Menampilkan daftar tugas pengguna dan progress penyelesaian tugas.



\### Add Task

Pengguna dapat membuat tugas baru dengan informasi:

\- Judul tugas

\- Deskripsi tugas

\- Prioritas tugas



\### Detail Task

Menampilkan informasi lengkap mengenai tugas yang dipilih.



\### Edit Task

Pengguna dapat memperbarui informasi tugas yang sudah dibuat.



\## 🛠 Teknologi yang Digunakan



\- Kotlin

\- Android Studio

\- Jetpack Compose

\- Material Design 3

\- Room Database

\- MVVM Architecture
